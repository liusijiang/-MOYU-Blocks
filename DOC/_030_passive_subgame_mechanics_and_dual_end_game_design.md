## 一、终极极简原则：为什么“最简单”才具有最大成瘾性？

俄罗斯方块能统治游戏史四十余载，其秘诀只有一条：**极其简单的规则，涌现出无限深邃的博弈。**

如果我们在消除游戏下方添加一个系统：
- ❌ **错误的复杂化**：添加血条、攻击力、防御力、暴击率、装备、天赋树、几十种怪物（典型的打怪拼贴）；
- ❌ **错误的复杂化**：添加多层抽奖轮盘、暗金词缀、复杂概率表（典型的赌博拼贴）；
- ✅ **真正高级的简单（True Simplicity）**：
  - **只有一个核心指标**（如：温度、沙量、平衡度）；
  - **上盘动作直接拨动这个指标**（放块增加，消除减少）；
  - **这个指标到了红线，直接宣告游戏失败**；
  - **在主盘快死的时候，这个指标能救你一命**。

玩家不需要阅读任何教程，看一眼动画，0.5 秒内就能完全理解！

## 二、极简方案一：【引力熔炉与热力过载】（The Gravity Furnace）

这是最纯粹、最自然、也是与当前方块消除手感契合度最高的设计。

```
┌─────────────────────────────────────────────────────────────┐
│                      10x10 主消除棋盘                        │
│            [玩家单手拖拽 · 几何拼图 · 消除清行]               │
└──────────────────────────────┬──────────────────────────────┘
                               │
            ┌──────────────────┴──────────────────┐
            │  极简热力学闭环                      │
            │  · 放一个积木 ───> 熔炉温度 +5°C    │
            │  · 消除一行方块 ──> 熔炉温度 -20°C   │
            │  · 连消/多行 ─────> 强力降温喷雾     │
            └──────────────────┬──────────────────┘
                               ▼
┌─────────────────────────────────────────────────────────────┐
│             下方视窗（60px 高度）：【引力熔炉】              │
│                                                             │
│   [ 散热风扇 🌀 ]  ░░░░░░░░░████████  [ 78°C / 100°C ] 🔥   │
│                   (由蓝变红的温度进度条)                    │
│                                                             │
│   ★ 危机：温度达 100°C 熔炉直接熔毁过热，GAME OVER！         │
│   ★ 救赎：若棋盘死锁且熔炉处于安全低温，消耗冷气直接清空最底行│
└─────────────────────────────────────────────────────────────┘
```

### 2.1 极简规则（一句话说清）
- **放块升温**：每次往棋盘上放一个积木，底下的熔炉温度上涨 **+5°C**（因为主盘的质量压迫在产生热量）；
- **消行降温**：每次在棋盘上消除一行，熔炉瞬间释放冷凝排气，温度下降 **-20°C**；如果一次性消除多行或连击，直接降至安全冰点；
- **挂机自然回温**：如果玩家停下来思考超过 5 秒，熔炉每秒自动上升 **+2°C**。

### 2.2 双向死局（极简而刺激）
1. **死法一（空间塞满）**：传统的 10x10 棋盘积木放不下了；
2. **死法二（过热熔毁）**：玩家连续放方块但一直无法消除，或者发呆太久，温度飙升达到 **100°C**，熔炉当场过热爆炸，游戏结束！
> **心理体验**：彻底治好了消除游戏“挂机无脑发呆”的毛病。玩家时刻听着风扇越来越急促的轰鸣声，必须争分夺秒地寻找消除机会，手心出汗，刺激感拉满！

### 2.3 极简救赎（绝处逢生）
- 当棋盘上的积木放不下（检测到死锁）时：
  - 如果熔炉处于**低温安全区（温度 < 40°C）**，说明玩家之前打得很漂亮、降温很充足；
  - 熔炉自动触发【紧急泄压喷射】，将最底下的一行方块瞬间蒸发吹走，棋盘腾出空间，死锁解除！
  - 代价：温度直接拉高到 85°C 的危险边缘。

## 三、极简方案二：【重力沙漏与时间滴落】（The Gravity Hourglass）

把“时间”作为唯一的变量，最符合人类直觉。

```
┌─────────────────────────────────────────────────────────────┐
│                      10x10 主消除棋盘                        │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               │ 消除的方块化作金沙掉落
                               ▼
┌─────────────────────────────────────────────────────────────┐
│             下方视窗（60px 高度）：【引力沙漏】              │
│                                                             │
│   ⏳ [ 上层存沙: 15秒 ]  =====>  ⏳ [ 下层漏沙: 消耗中 ]     │
│   (消行 = 补沙延寿)               (沙子漏光 = GAME OVER)   │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 极简规则
- 下方就是一个静静平躺的微型光子沙漏；
- 初始拥有 **20 秒** 沙量，沙子匀速漏下；
- 玩家在棋盘上每消除 1 行，消除的方块化作金沙汇入沙漏，**增加 +5 秒**（最多囤积 30 秒）；
- 连击（Combo）每多一层，额外增加 +2 秒。

### 3.2 双向死局
1. **死法一**：盘面塞满，手牌无法放下；
2. **死法二**：沙漏里的沙子彻底漏光（时间归零），时钟停摆，直接 Game Over。

### 3.3 极简救赎
- 如果盘面死锁，但沙漏里还有超过 **10 秒** 的余量；
- 沙漏发生【时间逆流震波】，自动震碎棋盘最中间的 2x2 四个方块，扣除 8 秒沙子；
- 玩家利用争取到的空间继续操作。

## 四、极简方案三：【天平平衡法码】（The Cosmic Counterweight）

完全立足于“重量与平衡”的物理直觉。

```
┌─────────────────────────────────────────────────────────────┐
│                      10x10 主消除棋盘                        │
└──────────────────────────────┬──────────────────────────────┘
                               │
            ┌──────────────────┴──────────────────┐
            │  左倾（危险）：在棋盘放块，左盘加重   │
            │  右倾（回正）：在棋盘消行，右盘加重   │
            └──────────────────┬──────────────────┘
                               ▼
┌─────────────────────────────────────────────────────────────┐
│             下方视窗（60px 高度）：【引力天平】              │
│                                                             │
│       ▲ [倾斜角: -12°]       ─── 保持在 [-30°, +30°] 内     │
│      / \                                                    │
│    [左: 盘面积压] ⚖️ [右: 消除功勋]                          │
│                                                             │
│   ★ 危机：天平单向偏角超过 30° 彻底倾覆倒塌，GAME OVER！      │
└─────────────────────────────────────────────────────────────┘
```

### 4.1 极简规则
- 下方是一个水平居中的微型天平指针；
- 棋盘上每放一个积木，天平往**左倾斜 2°**（代表棋盘上的杂物积压）；
- 棋盘上每消除一行，天平往**右回正 8°**（代表清除了重力负担）；
- 玩家的目标：通过有节奏的放置与消除，让天平始终保持在水平线附近。

### 4.2 双向死局
1. **死法一**：棋盘塞满放不下；
2. **死法二**：连续放了十几个积木却一次行都没消掉，天平左边彻底沉底，倾斜度超过 **30° 倾覆**，天平翻车砸碎主盘，Game Over！

### 4.3 极简救赎
- 当棋盘死锁时，若天平此时恰好处于**绝对平衡态（倾角在 ±3° 之间）**；
- 触发【完美谐振】，天平底座升起一道光柱，震碎主盘最外圈的一圈方块解开死锁。

## 五、“盘面放不下积木”的极简救赎逻辑

比对当前源码（`src/App.tsx` 和 `src/utils/gameLogic.ts`）：
目前的死亡逻辑非常生硬：
```typescript
const canAnyPieceFit = piecesToValidate.some((p) => canPieceFitAnywhere(newBoard, p));
if (!canAnyPieceFit) {
  setGameOver(true); // 瞬间暴毙
}
```

在引入极简被动副游戏后，救赎判定变得极其自然、清晰：

```
                    canAnyPieceFit === false (棋盘放不下了)
                               │
                               ▼
                  检查副游戏单一指标是否及格？
                 (例如：熔炉温度是否处于安全区？)
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
        【及格：触发一次救赎】             【不及格：弹药耗尽】
   · 自动消除最底下一行方块               · 真正宣布 GAME OVER
   · 副指标付出巨大代价(温度飙升至85°)     · 玩家心服口服
   · 游戏继续！(单局最多救 1 次)
```

**为什么这能大幅提升爽感？**
1. **去除了发牌杀的委屈感**：玩家手牌卡死时，如果他前面消行很漂亮（熔炉很凉快），系统会因为他的优秀表现奖励他一次自动清行救活；
2. **代价直观可见**：救活之后温度条瞬间变红、风扇狂转，危机感立刻扑面而来，绝不是无脑的免费复活。

## 六、三大极简方案对比与最终推荐

| 比较维度 | 方案一：引力熔炉（温度条） | 方案二：引力沙漏（时间流） | 方案三：引力天平（平衡角） |
| :--- | :--- | :--- | :--- |
| **规则复杂度** | **极低（看温度，放块热消行凉）** | 低（看倒计时沙子） | 中（看倾斜角度） |
| **UI 占用高度** | **仅需 40px~60px（一个精致细长条）** | 约 50px | 约 60px~80px |
| **视觉直觉** | **红/蓝渐变色条，直观震撼** | 沙子粒子掉落 | 天平摇摆动画 |
| **致死紧张感** | ⭐⭐⭐⭐⭐（轰鸣升温，逼迫快速操作）| ⭐⭐⭐⭐（时间滴答倒数）| ⭐⭐⭐（机械倾斜）|
| **防发呆/促连击**| **效果最好（挂机自动升温）** | 效果好（挂机沙子漏完）| 无法惩罚纯挂机思考 |

### 🎯 最终极简推荐：【方案一：引力熔炉（The Gravity Furnace）】

**推荐理由**：
1. **极度简单**：玩家只要知道“**别让温度烧到 100°C**”，完全没有任何额外学习成本；
2. **极简 UI**：只需要在原本的底部空白区放一个**纤细优雅的动态能量/温度槽**（带微型风扇和散热气孔微粒），甚至只有 40px 高，完全不挤占任何屏幕空间；
3. **完美解决问题**：
   - 彻底解决了“无脑挂机思考”的沉闷，逼出玩家单手行云流水的操作本能；
   - 熔炉安全时能救你一次死锁；
   - 温度过热时能直接炸毁游戏结束；
   - 既简单，又刺激，而且开发与运行极为轻量稳定！
