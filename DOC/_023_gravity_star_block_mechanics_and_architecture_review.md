## 一、引力星块概念与三维物性界定

### 1.1 什么是引力星块（Resonance Piece）？

在《摸鱼方块》的规则宇宙中，**「引力星块」**（在代码中标记为 `isResonancePiece: true`，UI 上赋予耀眼的“引力星块”紫金渐变微型徽章）是玩家通过精湛的消除技巧与连击步数积攒满 100% 引力共鸣能量后，由手牌托盘中的常规积木原位发生高维粒子蜕变后生成的**战略级终极道具**。

它不再是一个受制于棋盘格子拥挤、只能被动填充平面的几何色块，而是一枚携带着**宇宙级引力奇点（Gravitational Singularity Core）**的毁灭与重构装置。

### 1.3 引力星块在整体游戏心流中的战略定位

在传统消除积木游戏中，当棋盘格子被垃圾碎块逐渐填塞、空间熵增至极限时，玩家往往不可逆地滑向 Game Over，缺乏主动反抗的手段。

引力星块的设计初衷，正是**打破这种被动窒息感**：
1. **明确的期待感（Anticipation）**：玩家每一次普通消除都在为右上角的引力能量槽注入燃料，即使当前盘面凌乱，只要能量接近 100%，就能产生“撑到大招就能翻盘”的强烈信念；
2. **绝对的掌控感（Agency）**：引力星块赋予玩家全屏十字贯穿的高能瞄准标线，玩家可以自由巡游、精密校准，自主选择切除最恶性的空间死锁柱；
3. **多巴胺的爆发峰值（Catharsis）**：落盘瞬间的横纵激光、全屏闪白、厚重低音震颤与连带激发的 5x5 裂变大雪崩，带来无与伦比的“绝地翻盘”快感。

## 二、引力星块的演化史：从“被动死核”到“战略核武”

梳理 `/DOC` 路径下的历史设计文档，引力星块相关机制经历了一场从雏形探索到数学死锁、再到彻底重构的深刻演进。

### 2.1 任务 004 ~ 008 时期：单纯 1x1 重力方块的局限
- **004 机制初探**：首次提出了当单次消除达两行以上时，在棋盘空位随机生成一个 1x1 的重力方块。消除重力方块时，仅触发残留在场上的积木碎片下落；
- **008 规则公正性修正**：将重力方块被消除时的效果扩大为“全场所有积木公正垂直下落”，但暴露出生成随机性过高、缺乏前置博弈悬念、且下落直接全屏倾泻导致局部细节缺失的问题。

### 2.2 任务 010 时期：引力共鸣蓄能槽诞生与被动附魔
- **核心突破**：用户坚决否决了需要额外按键的“暂存仓（Hold Slot）”，确立了“纯被动释放”哲学。
- **机制引入**：
  - 设计了 `ResonanceBar`（引力共鸣槽），收集每次消除的能量增量；
  - 满能 100% 时，确立了**“原地动态附魔（In-Place Morph）”**时序：不插入额外发牌周期，直接将托盘中已有的首个可用方块赋予星河光晕，诞生了最初形态的“引力星块”；
- **010 的早期局限**：当时引力星块落盘后，仅仅是将方块最底部的单元格变为一颗普通的紫色重力核心，随后**静止定格在棋盘上**，依然必须等待下一次甚至下几次落子凑出行/列消除，才能激活其能力。

### 2.3 任务 011 时期：5x5 震碎引信与同质化视觉冲突的诊断
- **机制演进**：将消除引力核心的效果从全场无脑掉落调整为“5x5 区域定向粉碎为 1x1 碎块”，碎块下落若引发行消除，则解锁全场大雪崩。
- **暴露的核心痛点**：
  1. **视觉混淆**：托盘中的“引力星块”与棋盘上的“引力核心”同为紫金/紫罗兰色调，玩家难以区分；
  2. **大雪崩不可达假象**：5x5 碎石下落要想在 10x10 的全宽网格中纯靠运气凑满整整 10 格满行，经蒙特卡洛随机模拟测算，概率不足 **2.76%**！全局大雪崩沦为“幽灵代码”，玩家产生强烈的落空感与被欺骗感。

### 2.4 任务 013 ~ 016 时期：奇点坍缩、落盘即爆与 100% 确定性准星瞄准预览
在任务 013 中，设计团队对代码进行了深度走查，将上述缺陷定性为“引力大招的延迟挫败与猝死悖论”。紧接着在 014~016 任务中打出了组合重构拳：
1. **推翻“延迟埋雷”，确立“落盘即爆（Impact Detonation）”**：
   引力星块不再需要玩家后续辛苦凑行去消除，只要触碰棋盘合法位置，**在落盘瞬间（T=0ms）立刻爆发引力奇点坍缩**，强制扫出 19 格横纵贯穿十字激光（Singularity Cross Blast），必定清空整行与整列！
2. **重构大雪崩激活阈值**：
   只要本回合触发了 5x5 裂变，且碎石下落引发了**任意一行新的消除（`cascadeStep > 1 && totalLines >= 1`）**，系统 100% 确定性解锁全局大雪崩！
3. **确立绝对确定性发射源（Fixed Core Entity Anchor）**：
   在 015 和 016 任务中，彻底论证并排除了“以玩家手指/鼠标指针为十字中心”的劣质方案（杜绝了移动端触控 68px 抬升与抓取点随意带来的激光漂移），将十字爆破交点严格、永久固化在积木本身的“引力星核晶元单元格”上；
4. **引入高精度准星瞄准 HUD（Singularity Crosshair Reticle）**：
   在拖拽过程中实时投射等离子双轨瞄准标线、目标受击晶格化预览与场上既有引力核心的 5x5 预警联动，使玩家的博弈体验从“盲目开火”升华为“战术狙击”。

## 三、引力能量闭环：从蓄能到原地附魔

### 3.1 能量来源数学模型与权重规约

在 `src/utils/gameLogic.ts` 中，引力共鸣槽的能量注入通过纯函数 `calculateResonanceDelta` 进行精确量化：

$$\Delta \text{Energy} = \text{BaseDelta}(\text{clearedLines}) + \text{CascadeBonus}(\text{cascadeStep})$$

#### 算子分级表：
1. **普通有效放置（`clearedLines === 0`）**：
   - 基础增量：$+2.0\%$（步步有积累，缓解沉没成本）；
2. **单线常规消除（`clearedLines === 1`）**：
   - 基础增量：$+7.0\%$；
3. **双线高阶消除（`clearedLines === 2`）**：
   - 基础增量：$+18.0\%$；
4. **三线及以上爆发消除（`clearedLines >= 3`）**：
   - 基础增量：$+35.0\%$；
5. **多级物理级联追加奖励（`cascadeStep > 1`）**：
   - 每提升一级级联，追加 $+ (\text{cascadeStep} - 1) \times 10.0\%$ 能量加成。

该数学模型保证了玩家在常规平稳对局中大约经过 **8 ~ 12 步** 即可攒满一次大招；而一旦打出高阶双线或重力连锁，最快只需 **3 ~ 4 步** 就能瞬间充盈。

### 3.2 蓄能槽（ResonanceBar）的视觉与状态流转

组件 `src/components/ResonanceBar.tsx` 将能量状态转化为精密的机械电子仪表语言：
- **未满能态（0% ~ 99%）**：
  - 左侧 `Atom` 图标以 6 秒为周期平缓自转，呈典雅的淡紫色；
  - 能量轨道呈现从深蓝、紫罗兰到紫红的渐变流光；
  - 轨头带有白热光子微粒，直观指示当前百分比。
- **满能过载态（100%）**：
  - `Atom` 图标升华为明黄色（`text-amber-300`），自转速度飙升至 2 秒的高频过载运转；
  - 状态文案切换为带 `Sparkles` 闪烁的 `引力大招蓄满·当前首块已赋能!`；
  - 能量轨道激活 `animate-pulse` 高饱和度紫粉金流动光晕，并在外围激起一圈金色发光辉光（`ring-1 ring-amber-400/80`）。

### 3.3 满能瞬间的“托盘原地动态附魔”时序

在 `src/App.tsx` 的回合收敛阶段（`executePlacePiece` 末端），系统检测能量临界点：

```typescript
// App.tsx: 任务 010 原地附魔逻辑
if (!isResonancePiece) {
  const delta = calculateResonanceDelta(totalClearedInTurn, maxCascadeStep);
  const nextEnergy = Math.min(100, resonanceEnergy + delta);
  setResonanceEnergy(nextEnergy);

  if (nextEnergy >= 100) {
    // 检索托盘中首个非空、非微晶基石、非已附魔的积木
    const targetIdx = nextPieces.findIndex(
      (p) => p !== null && !p.isResonancePiece && !p.isKeystone
    );
    if (targetIdx !== -1) {
      nextPieces[targetIdx] = {
        ...nextPieces[targetIdx]!,
        isResonancePiece: true,
      };
      // 触发高维附魔音效
      sound.playShieldRestoredSound();
      // 弹出即时 Toast 提示
      setEliminationToast({
        id: `resonance_morph_${Date.now()}`,
        title: '引力共鸣100%! 首块蜕变为引力星块!',
        scoreBonus: 0,
        totalLines: 0,
      });
    }
  }
}
```

**设计哲学解析**：
这一设计彻底杜绝了传统游戏中“大招充满后必须等下一次发牌甚至重新洗牌”的延迟断层。玩家这一手刚凑出高分，眼看着托盘里原本普通的方块周身瞬间卷起紫金星云、头顶弹跳出“引力星块”徽章，获得了极其强烈的正反馈激励。

### 4.2 星核晶元局部坐标绝对锚定数学模型

为什么不能以玩家鼠标触点作为爆破发射源？文档 `_015_` 给出了决定性的论证：
若以触点为准，玩家捏住积木左上角与捏住右下角放置在同一网格时，十字激光扫过的行与列将发生不可预测的随机漂移，导致因果律崩溃。

因此，代码在 `src/utils/gameLogic.ts` 中固化了确定性算法：
```typescript
export function findBottomMostCellInPiece(shape: number[][]): { r: number; c: number } {
  let maxR = -1;
  let bestC = -1;
  for (let r = 0; r < shape.length; r++) {
    for (let c = 0; c < shape[r].length; c++) {
      if (shape[r][c] === 1) {
        if (r > maxR) {
          maxR = r;
          bestC = c;
        } else if (r === maxR && (bestC === -1 || c < bestC)) {
          bestC = c;
        }
      }
    }
  }
  return { r: Math.max(0, maxR), c: Math.max(0, bestC) };
}
```
**数学含义**：星核晶元永远固定在积木实体**几何形态最底层、水平最靠左**的有效单元格中。无论玩家从哪个像素拖拽，只要积木落在 `(targetRow, targetCol)`，奇点中心 $\mathbf{P}_{\text{singularity}}$ 就是确定且唯一的：
$$\mathbf{P}_{\text{singularity}} = (R_{\text{target}} + r_{\text{core}}, \; C_{\text{target}} + c_{\text{core}})$$

### 5.1 第一接触点星核脱落与 1x1 核心固化
引力星块落盘后，其母体并不会原封不动变成铁板一块：
1. 系统根据 `findBottomMostCellInPiece` 寻找到星核单元格在局部矩阵中的坐标 `(coreR, coreC)`；
2. 母体方块对应单元格被置零，从原实体中剥离；
3. 在棋盘坐标 `(coreRow, coreCol)` 处独立生成一枚永恒的 **1x1 引力核心实体**（`isGravityBlock: true, color: GRAVITY_BLOCK_COLOR`）；
4. 这一精妙的拓扑分离，使得母体剩余部分成为可以受重力自由沉降的结构，而星核则就地生根作为未来连锁的引信。

通过 `calculateSingularityCrossBlast`，系统无视棋盘格子原本是否填满，强制将 `coreRow` 整行与 `coreCol` 整列纳入 `clearedRows` 与 `clearedCols`：
- 整整 19 个单元格内的既有方块在第一级联步（`cascadeStep === 1`）被**物理绝对蒸发**；
- 屏幕爆发 `singularityBlastCenter` 专属全屏琥珀等离子金色光幕（`Board.tsx` 第 223~260 行）；
- 扬声器播放瞬态冲击力拉满的奇点坍缩声 `playSingularityBurstSound`；
- 引力共鸣能量当场清零（`setResonanceEnergy(0)`），完成大招交接。

### 5.3 5x5 裂变引信与全场大雪崩的确定性临界跃迁
若十字激光穿透了棋盘上之前遗留的 1x1 引力核心（或触发了星核自身的冲击震碎）：
- 该核心周围半径 2 格内（$5\times 5$ 区域，最多 25 个网格）的所有积木单元被引力波瞬间震裂，**强制解构为独立的 1x1 最小碎石**（`isDebris: true, shape: [[1]]`）；
