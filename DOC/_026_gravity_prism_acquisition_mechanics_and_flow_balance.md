## 一、核心命题与设计哲学纯净化（Purified Design Philosophy）

### 1.1 为什么必须坚决剔除“路径 2（手牌/共鸣槽分级兑换）”？

在初步推演中，“路径 2（将能量槽拆为 50% 折向小招与 100% 终极大招）”看似提供了丰富的博弈选择，但经过深入复盘，它严重违背了优秀益智游戏的**“心智清晰原则（Mental Clarity）”**：

```
【被否决的路径 2 的致命心智缺陷】

  玩家大脑本能认知:  [ 0% ────────────────────────── 100% 满能量直接放大招! ] (纯粹/清晰)
                                      ▲
                                      │ (横插一杠)
  路径 2 造成的认知断层:  [ 0% ─────── 50% ─────── 100% ]
                                      │
                         • 托盘方块突然变色变身，玩家思考被强行打断
                         • 产生“不小心把 50% 能量浪费了”的患得患失感
                         • 稀释了 100% 终极引力大招的神圣感与爽快感
```

1. **认知负荷过载**：玩家注意力必须聚焦在棋盘几何与消除预判上。在能量槽上增加多档位分段，会逼迫玩家像“做会计对账”一样计算能量，破坏流畅的消除心流；
2. **手牌状态精神分裂**：托盘里的方块一会儿是普通俄罗斯方块，一会儿变成绿色折向块，一会儿又变紫金大招，手牌的不可预测性会严重干扰高水平玩家的落子规划；
3. **因此决议**：**坚决废黜路径 2。能量槽 100% 归还给「引力星块（Resonance Piece）」，保持从 0 到 100% 蓄力放大招的绝对神圣与纯粹。**

### 1.2 极简设计铁律：纯棋盘原位衍生，手牌与能量槽零污染

引力折向棱镜**完全不从托盘生成、不占手牌槽位、不依赖外部仪表盘**。
它就像棋盘上的矿藏或地雷一样——**完全由玩家在棋盘上用出色的技巧消除打出来，并静静卧在棋盘格中等待引爆**！

### 1.3 对称物理因果律：横消生“核”，纵消生“棱”

自然界具有绝妙的对称性，《摸鱼方块》的物理引擎也应当具有最工整的因果律：

```
                    【对称物理因果律：横纵正交双子引信】

          ┌─────────────────────────────────────────────────────────┐
          │                    高阶多线技巧消除                     │
          │         (clearedRows + clearedCols >= 2 且 >= 2线)      │
          └────────────────────────────┬────────────────────────────┘
                                       │
                      ┌────────────────┴────────────────┐
                      ▼                                 ▼
             【纯横向消除为主】                【包含纵向消除】
             (clearedCols === 0)              (clearedCols >= 1)
                      │                                 │
                      ▼                                 ▼
           孕育: 1x1 引力核心 (Gravity Core)  孕育: 1x1 引力折向棱镜 (Gravity Prism)
           • 色彩: 曜石深黑 + 等离子青        • 色彩: 量子深黑 + 电光翡翠绿
           • 职能: 5x5 裂变垂直下坠引信       • 职能: 瞬态横向脉冲缝合深井
           • 哲学: 垂直向下力学的极点         • 哲学: 水平横向力学的自愈
```

- **消除横行（不伤及竖列）**：地盘被压低，生成**引力核心**，后续引爆释放纵向重力雪崩；
- **消除纵列（切开了竖井）**：地貌被割裂，生成**引力折向棱镜**，后续引爆释放横向引潮脉冲，把被切开的伤口重新缝合！

**逻辑一秒即懂，因果完全闭环，没有任何多余设定！**

## 三、引力折向棱镜的棋盘孕育数学模型（The In-Board Spawning Model）

### 3.1 孕育触发条件：纵消诱导裂变

系统在每次落子消除结算时，调用统一的生成派生裁决：

```typescript
// 派生判定公式
const totalLines = clearedRows.length + clearedCols.length;

if (totalLines >= 2) {
  if (clearedCols.length === 0) {
    // 纯横向双消/三消 -> 孕育引力核心 (Gravity Core)
    spawnGravityCore(...);
  } else if (clearedCols.length >= 1) {
    // 包含纵向消除 (双纵消、或横纵十字交错消) -> 孕育引力折向棱镜 (Gravity Prism)!
    spawnGravityPrism(...);
  }
}
```

- **设计直觉**：玩家只要打出了一次包含纵向的优秀连消（例如消了一竖一横，或两竖），系统立刻奖励一颗引力折向棱镜；
- **自愈前置**：这颗棱镜恰好诞生在玩家刚刚撕开纵向裂缝的时刻，作为战术储备留存在棋盘上。

### 3.2 坐标选址算法：裂痕交叉点锁定
在 `checkAndSpawnGravityPrism` 中：
1. **第一优先级（交叉点断口）**：
   优先选择本次消除中，纵列与横行相交的空网格坐标 $(r, c)$（即消除中心断口）；
2. **第二优先级（纵消槽位中段）**：
   若为纯双纵消（无横消），在被消除纵列的纵向中段空位（$Row \in [3, 6]$）选取；这个位置处于棋盘“腰部”，一旦引爆能对全场产生最大的横向拍紧重构效应；
3. **保底优先级**：全场任意合法空网格。

### 3.3 推进朝向计算：地貌势能自动寻优（Topological Energy Minimization）

引力折向棱镜的推进方向（`◄` 向左 或 `►` 向右）**绝对不是随机盲盒**，而是算法在生成瞬间根据棋盘左右两侧的填充度智能裁决：

```typescript
function calculatePrismVectorDirection(board: BoardState): 'left' | 'right' {
  let leftMass = 0;
  let rightMass = 0;

  for (let r = 0; r < 10; r++) {
    for (let c = 0; c < 5; c++) {
      if (board[r][c] !== null) leftMass++;
    }
    for (let c = 5; c < 10; c++) {
      if (board[r][c] !== null) rightMass++;
    }
  }

  // 势能寻优铁律：总是朝向“积木密度更大”的一侧推进！
  // 理由：向密集侧推挤，最容易让残缺断壁瞬间凑满垂直列消除，同时在稀疏侧释放大平原！
  return leftMass >= rightMass ? 'left' : 'right';
}
```

- 生成后，该实体携带固定的 `vectorDirection: 'left' | 'right'`，并在晶体表面**明牌雕刻着向左或向右的动态流光箭头**；
- 玩家一目了然，拥有完全透明的战术预期。

### 4.1 激活触发条件：常规消行穿透
- 当玩家后续的放置消除了包含棱镜所在的横行（`clearedRows.includes(prism.startRow)`）时，棱镜被正式引爆；
- （注：若仅消除了竖列，因棱镜本身就是用来解决纵向问题的，优先通过消横行来横向释放）。

### 4.2 阶梯 1：瞬态横向脉冲（Lateral Impulse, 120ms）
- **物理运动模型**：
  同一水平线上的所有方块单元格，沿着棱镜的 `vectorDirection` 极速滑动（耗时 120ms），如同受到强力横向重力风暴；
  - 若为向左（`left`）：每行方块向左滑动贴靠，直到触碰左侧边框（Col 0）或左侧已有的静止方块；
  - 若为向右（`right`）：每行方块向右滑动贴靠，直到触碰右侧边框（Col 9）或右侧已有的静止方块；
- **视觉冲击**：棋盘上原本被深井隔成孤岛的方块，瞬间像抽屉一样“刷”地一下撞在一起并拢，缝合感极其强烈。

### 4.3 阶梯 2：纵向列闭合检测与连击跃迁
- 横向拍紧后，原本各缺一两格的纵向石柱，在并拢后极大概率瞬间凑满一整列（10格全满）；
- 系统立刻触发纵列消除动画，鸣响清脆的连击音效，极大释放玩家的压抑感。

### 4.4 阶梯 3：常态向下重力无缝接驳（Vertical Settle, 160ms）
- 水平脉冲释放完毕后，**系统物理引擎立刻无缝切回玩家熟悉的垂直向下牛顿重力**；
- 调用现有的 `computeStructuralSupportDrops`：刚才被横向推移到深井正上方的碎石与积木，由于脚下悬空，带着真实的加速度呼啸坠入井底深坑，把底部彻底填实！

### 4.5 阶梯 4：横行平稳消除检测与稳态收敛
- 下坠完成后再次进行常规消除检测，若达成消除继续递归连锁，直到全场达到牛顿力学完全静态平衡。

## 五、战术预警与视听通感工程（Visual & Acoustic Identity）

根据 Anti-Slop 准则，引力折向棱镜必须拥有极其高级、与现有道具泾渭分明的视听工业美学。

### 5.1 视觉材质：电光翡翠绿与量子自愈光环（Electric Emerald）
- **底色渐变**：
  `bg-gradient-to-br from-slate-950 via-emerald-950 to-teal-950`
  深邃的暗黑底质，折射出莹莹生辉的深绿色量子微光；
- **高能辉光边框**：
  `border-2 border-emerald-400 rounded-lg shadow-[0_0_16px_rgba(16,185,129,0.85)] ring-2 ring-emerald-300/70`
- **色彩通感**：
  绿色在心理学上直连“自愈、修复、重连与生机”，让玩家一眼看去就产生“这是用来修复破损地貌的神器”的安全感与期待感。

### 5.2 动态符号：双重离子推进箭头（Chevrons）
在晶体正中央嵌入动态流光推进器：
- 向左棱镜：内嵌 Lucide 图标 `ChevronsLeft`；
- 向右棱镜：内嵌 Lucide 图标 `ChevronsRight`；
- 赋予 `animate-pulse` 与微小的水平往复位移（Translate $\pm 2\text{px}$），仿佛一台时刻蓄势待发的离子推进引擎。

### 5.3 专属程序化 Web Audio 合成音效
在 `src/utils/audio.ts` 中构建专属合成链（纯算法合成，零外部资源依赖）：
1. **棱镜生成音效（`playPrismSpawn()`）**：
   - 频率由 350Hz 指数级平滑抬升至 920Hz 的双正弦波，叠加快节奏的高频离子颤音，传递出“磁场偏转线圈就绪”的清脆科技感；
2. **横向合拢啸叫与撞击（`playLateralFlush()`）**：
   - 中频粉红噪声通过带通滤波器由 1200Hz 快速衰减至 300Hz，混合金属导轨滑行声与沉闷的碰撞低音，再现巨型空间闸门轰然闭合的雄浑力量感。

export interface PlacedPieceEntity {
